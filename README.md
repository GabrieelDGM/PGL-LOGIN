📱 Navegación en React Native con Expo Router — Resumen de la Actividad

Esta práctica consiste en crear una aplicación móvil utilizando React Native + Expo Router, implementando distintos tipos de navegación y reciclando contenido trabajado anteriormente.
El objetivo es aprender a estructurar pantallas, usar un Drawer, Tabs y navegar entre vistas.

✔️ Requisitos Implementados
1. Pantalla de Bienvenida

Pantalla inicial de la app.

Contiene:

Un mensaje de bienvenida.

Una imagen.

Un botón que permite navegar al portfolio (pantallas con Tabs).

2. Drawer Navigation

Se añadió un Drawer (menú lateral) como navegación principal.

La pantalla por defecto al abrir la app es la de bienvenida.

El Drawer contiene:

Portada (Bienvenida)

Portfolio (Tabs)

Lista de Animes

3. Pantallas de Portfolio (Tabs Navigation)

Dentro del Drawer, la sección Portfolio abre dos pestañas:

Hobbies

Mi Repositorio (QRCode)

Ambas están organizadas mediante navegación tipo Tabs.

4. Lista de Animes

Se recicló la lista de la práctica anterior.

Convertida en una pantalla independiente.

Accesible desde el Drawer.
